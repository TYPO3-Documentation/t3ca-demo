The news as cards (design/index.html, section "News"). Template layout "home": the newest news on the home page. The heading is the header of the content element, and the link to all news goes to the page the plugin names as list page (tab "Additional"). Template layout "events": the upcoming events on the home page (design/index.html, section "Events"), as a list with a date badge, and a link to the plugin's list page. Template layout "eventsPage": the same list on the events page itself. Which news are events and which are still to come, the plugin decides (EXT:eventnews, tab "Eventnews"). Without a template layout: the list page itself, with pagination.
