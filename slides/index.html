get.typo3.org
Where to look: get.typo3.org, ten seconds, always current. Also typo3.org roadmap (support dates) and the maintenance release schedule on typo3.com. Or give the AI the official source: "Check get.typo3.org". Or connect the dev companion: MCP works with any client, not only Claude.
Section: giving the AI the right knowledge. Clear signals.
MCP, the Model Context Protocol: one standard plug between AI tools and the things they can use, like documentation, a database or a browser. An open standard: Claude Code, OpenCode, Cursor and others speak it. "USB-C for AI."
The TYPO3 Dev Companion: an MCP server for TYPO3. Current, version-bound TYPO3 knowledge for 12.4, 13.4, 14.3 and main. Runs locally, only reads, writes nothing into your installation. Plus 15 task skills (site package, content elements, extension upgrade…). Experimental, 0.x.
❯ ddev composer require --dev "typo3/dev-companion:@dev"
❯ ddev exec vendor/bin/typo3-dev-companion install
Installing it, as Claude did in stage 02. Or just ask your AI: "Install https://github.com/TYPO3/dev-companion as a development dependency and configure it so that my AI client can use it." Restart the AI session afterwards.

Section: themes. Same dancer, same dog, a different costume each time. In TYPO3 the costume of a website is the site package.
What WordPress calls a theme, TYPO3 calls a site package. It is an extension: page layouts, Fluid templates (TYPO3's Twig/Blade), CSS and JS, and the site's settings, all under version control.

Linawhat about data privacy and security?
ClaudiaThe form is technically sound, but my design has one real security flaw. A spammer can enter a stranger's address and their own text, and the municipality sends it for them, from its own domain.
The copy to the sender: whatever address is typed in gets the message. A spam relay, and one typo sends a citizen's message to a stranger. Claudia found her own flaw, because I asked. I decided: remove the copy.
Spam. Fishing it out before it reaches the inbox.
