# Fonts

Both fonts are licensed under the SIL Open Font License 1.1 (OFL.txt).

- `SourceSans3-latin*.woff2`: Source Sans 3 by Adobe, the font of the Mto Safi design,
  downloaded from Google Fonts.
- `NotoSansEthiopic.ttf`: Noto Sans Ethiopic Bold by Google, for the Amharic on the
  farewell slide, copied from Ubuntu's fonts-noto-core package.
- `NotoSansArabic.ttf`: Noto Sans Arabic Bold by Google, for the Arabic in part 2,
  from the same package.
