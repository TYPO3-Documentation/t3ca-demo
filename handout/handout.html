AI meets TYPO3

From prompt to site package, grounded in the official docs · TYPO3 Camp Africa 2026, Diani · Lina Wolf

In the talk an AI agent, Claudia, built a TYPO3 site for Mto Safi, a fictional municipality on the Kenyan coast, from a static HTML design. Every step is recorded and lives in the repository github.com/TYPO3-Documentation/t3ca-demo. This handout collects what to take home.

1 Where to run your AI

  • In the browser (ChatGPT, Claude.ai, Gemini) the AI can't see your project and can't try what it suggests. Fine for questions, not for building a site.
  • In the IDE the AI competes with the IDE for memory and CPU; an older laptop struggles. Even on a strong one the IDE keeps re-indexing files the AI is still changing. Use the IDE to look at the diff, but don't run the AI in it.
  • In the terminal (Claude Code, OpenCode, Cursor CLI; also Codex CLI or Gemini CLI) it feels like chatting with a colleague: describe what you want, no commands or flags to remember. Several agents can work in parallel. Give yours a name; mine is Claudia.

2 Name the TYPO3 version

An AI only knows what was in its training data. TYPO3 gets a new LTS version about every 18 months and bug fix releases every few weeks, so the AI's own knowledge is almost always behind. Some AI tools search the web, some can't, and a local model (for example OpenCode with Ollama) usually has no internet at all.

  • Name the version yourself: Install TYPO3 14.3 LTS with DDEV and Composer.
  • Look it up: get.typo3.org (current versions and support dates), the roadmap on typo3.org, and docs.typo3.org (every manual has a version switcher).
  • Or connect the official docs through MCP, see the next section.

3 MCP and the TYPO3 Dev Companion

MCP, the Model Context Protocol, is an open standard for connecting AI tools to outside capabilities. The AI client starts an MCP server, asks which tools it offers, and calls them when the model asks for it; the messages are JSON-RPC. It does for AI tools what the Language Server Protocol did for editors: one server, usable from many clients.

The TYPO3 Dev Companion is an MCP server for TYPO3. It supplies current, version-bound TYPO3 knowledge for 12.4, 13.4, 14.3 and main, reads your installation, writes nothing into it, and runs locally. It also installs task skills such as site package development and content elements. It is experimental (0.x). Installing it in a DDEV project, as Claudia did in stage 02:

ddev composer require --dev "typo3/dev-companion:@dev"
ddev exec vendor/bin/typo3-dev-companion install

install writes the server into .mcp.json and the skills into .agents/skills; --agent=<id> writes them where a specific client reads them. Restart your AI session afterwards. Manual: typo3.github.io/dev-companion

Check that it works, and ask what it did:

Lina

Which icon identifier is the right one for a delete button in the TYPO3 backend?

Lina

4 A theme is a site package

What WordPress calls a theme, TYPO3 calls a site package: an extension with the page layouts, the Fluid templates (TYPO3's Twig or Blade), CSS and JavaScript, and the site's settings, under version control.

  • get.typo3.org/sitepackage: the Site Package Builder, a kickstarter.
  • The site package tutorial on docs.typo3.org, step by step. New in v14: the Camino theme as a ready-made starting point.
  • With an AI, ask for the options first. The scaffolding of the builder helps people find their way; an AI writes only the files it needs.

Lina, stage 03

How should I turn the static design in design/ into a TYPO3 v14 site package? What are the options, and which do you suggest and why?

5 Ask first, you decide, check

The prompts that worked best in the recordings were short questions, typos included. Ask for options and reasons, choose, then say "go":

  • we need a contact form, what ways can it be created and what can you recommend?
  • what about data privacy and security? · what about spam protection?
  • who maintains ke_search? · what does it cost? · is there a free option?
  • try installing the project fresh, do the import scripts etc work?

The copy of the contact form to the sender could send spam to any address.The AI found its own flaw, because it was asked about security.

Personal data: which law applies (Kenya's Data Protection Act, Ghana's Data Protection Act, Ethiopia's Personal Data Protection Proclamation, Nigeria's NDPA, South Africa's POPIA, the GDPR…), what the privacy policy says, how long messages are kept: the site owner decides, not the AI.
